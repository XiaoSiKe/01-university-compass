# v0.3.0 小范围学生试用指南

状态：**试用准备材料，尚未开展真实学生试用。** 本文件用于发现入门门槛、对话负担、AI 使用判断和学习检查中的问题，不用于宣称教学效果或职业收益。模型测试、模拟对话与人工编写的示范均不计为真实学生反馈。

## 参与方式与一次体验

建议由愿意参与的组织者邀请 3–6 名自愿学生，覆盖没有用过 AI、会用聊天工具但不会编程、已有一点编程经验等情况。专业和年级只是背景，不代替能力判断。每人任选一个当前需要的入口，首次约 20–30 分钟，可缩短、跳过问题或随时结束；已有自己的任务时优先使用。

开始前用平实的语言说明：“这是一个仍在改进的学习助手，想看看它是否能帮你处理现在的一件事。做不出来也有价值，我们在检查助手怎样帮助你。你可以不回答、改题、停止，也可以选择不留下记录。”不把参加试用与课程成绩、社团资格或奖励资格绑定；未经本人明确同意不保存原始对话或个人作品。

助手不自行邀请、联系、发送反馈请求或安排提醒。第二次体验由学生本人选择；无需为了完成试用重新交代已经提供的背景。若已给出尝试或具体错误，直接从那里开始，不额外安排一轮测评。

## 五个可选任务入口

每次选一项即可。首次完成后可结束，不要求学生走完全部入口，也不把选择不用 AI 记录为失败。

| 入口与可直接发送的话 | 首次应留下什么 | 变化与后续反馈 |
|---|---|---|
| **AI 适用性**：“我想用 AI 帮我处理一项课程任务，但不知道哪部分值得交给它。请用我现有的材料，帮我比较自己做、简单工具做和 AI 协助的做法。” | 本人目的、必要材料、质量标准；哪些部分适合辅助、哪些需要本人判断，或暂时不用 AI 的理由 | 改变一个条件，例如材料包含个人信息、结果无法核对、时间只剩十分钟，观察是否调整选择与材料范围 |
| **学懂一段材料（T01）**：“我刚开始学 AI，今天只有 20 分钟。我想用它帮助理解课程，但没有材料在手，请给我一次能检查自己有没有学懂的练习。” | 基于可靠材料的理解题、本人答案、一处核对或纠错；无材料时使用明确标记的原创模拟材料 | 在适合的变化题上暂时撤去辅助，记录能否解释关键关系；下次可换真实课程片段或延迟重试 |
| **核实一个结论（T02）**：“我有一段 AI 整理的说明，想知道哪些话有依据。请帮我用已有材料核对，没找到证据的地方先留着。” | 少量主张、对应材料、当前判断与未知项；引用必须实际支持结论 | 新增一份冲突材料，或提出原文未覆盖的问题，观察能否保留冲突与未知；不能访问原文时记录核验范围 |
| **选择工作流并做小成果（T03；有基础者可用 T04）**：“我想用两份校园公开活动规则做一页有依据的问答。只有手机，每周两小时，不想买工具。请帮我选择够用的做法，再做一个小成果。” | 需求、最简单可行流程、需要本人核对的环节和停止条件；一页有限问答或小功能，检查有答案、无答案和冲突三类问题 | 改变一条规则，观察是否修改与复查；有人提出上 Agent 时，先解释额外需求、成本和风险，允许保留固定流程；无运行条件则注明尚未运行 |
| **判断下一段学什么（T05/T06）**：“我不知道先把 AI 用于专业学习，还是学开发。请帮我用两项小体验比较一下，每项最多 20 分钟，不要求现在选职业。” | 同一主题下的有限体验、所获帮助、感兴趣和卡住的环节、下一段暂定选择 | 比较投入与支持是否接近，区分真实困难与想象中的替代方案；允许更正目标、停止或补一项最影响判断的体验 |

参考：[AI 判断、工作流与检查](../01-university-compass/references/ai-judgment.md)、[AI 实践卡](../01-university-compass/references/ai-practice.md)、[路径与起点](../01-university-compass/references/ai-pathways.md)。模拟材料和预制输出只训练对应能力，不能记作实际工具运行、真实规则核验或真实用户试用成功。

## 把成果检查与撤去辅助检查分开

**先帮助完成当前任务，再判断掌握；学生也可以选择只解决问题。** 需要解释、提示或完整示范时正常提供。AI 做出正确成果，可以记“成果检查通过”，本人能力仍可能是“尚未检验”。不要为了试用强迫学生独立答题，也不把主动求助当作负面结果。

需要观察学习时，与学生说明将换一个小条件，暂时不用刚才的参考答案或 AI 提示，看看哪些部分已经能自己做。只选一项与现有基础相符的关键能力，例如：

- 讲过平均数与中位数后，换一组条件，让学生解释哪种指标更适合当前问题；不只机械改数字，也不突然加入陌生概念。
- 做完资料问答后，给一个材料未覆盖的问题，观察能否指出缺信息，而非继续补猜。
- 修改过代码后，给一项相近的小需求，让学生解释、修改并用样例检查；只有纸面推演时不记为真实运行。

检验前不提前点明关键答案。学生不会时给回所需支持，记录提示程度，之后视需要再选另一题；不能把提示后的正确回答补记为独立完成。结果仍可能受题目难度、状态和材料影响，不作智力、人格或终身适合度评价。

若学生愿意，可在下次用真实材料或间隔后再试一次，分别记录即时与延迟表现。未实际开展、拒绝检查、没有合适材料或条件不足时，如实记“未检验”及简短原因，不补写结论。

这项安排受到学习研究与 AI 辅助学习实验的启发，是本项目的试用设计。高中数学短期研究不能证明本 Skill 对大学生有效；一次独立表现也不能证明长期学习收益。

## 最少记录与两类结果

优先使用匿名编号，如 P01，不记录姓名、学号、联系方式、精确学校班级或无关家庭信息。只有解释具体卡点需要时才记宽泛背景。默认只存短摘要；保存原话、截图或作品另由参与者决定，分享前删除个人信息和账号凭证。参与者可要求删除自己的试用记录。

建议记录表；未开展时保持空白，不填写虚构反馈：

| 字段 | 最小内容 |
|---|---|
| 编号、日期与运行条件 | 匿名编号、实际日期、Skill 版本；知道时记录宿主与模型 |
| 起点与约束 | 是否做过类似任务、设备、可用时间；不把自报“懂了”当证据 |
| 任务与本人目的 | 五入口之一或学生自带任务，一句话记录希望得到什么 |
| AI 适用性与人机分工 | 采用/未采用 AI 的理由，交给 AI 的部分，保留的人类判断；是否有可用的简单替代 |
| 工作流与停止条件 | 实际选择的流程、检查点、成本或时间上限；没有动态决策需要时是否避免增加 Agent |
| 助手实际帮助 | 解释、提示、完整示范或共同制作；是否反复提问、是否直接处理已给出的卡点 |
| 成果可用性 | 哪项标准的实际检查通过/失败；未运行或未真实使用则标未验证 |
| 本人掌握 | 关键能力、变化任务、能解释/纠错/修改的表现；是否撤去辅助、用了哪些提示 |
| 延迟或新材料检查 | 是否实际开展、条件和结果；未开展留待验证，不把即时表现替代延迟表现 |
| 卡点与反馈 | 一件最费力或无用的事、一处帮助；是否想继续，原话可选 |
| 下一次调整 | 保留、改方法、缩小、换路径或停止；指出哪条反馈导致变化 |
| 记录范围 | 只存摘要/另获同意保存作品；删除要求及实际处理状态 |

同一能力可用四个描述：**尚未检验、需要完整示范、在提示下完成、本次变化任务可独立完成**。它们只描述这次表现，不用于排学生高低。“作品通过”和“本人掌握未检验”可以同时成立；不要把它们合成一个总分。

## 反馈、退出与复盘

结束时最多问三个简短问题，可以不答：

1. 哪一步让你更清楚了，哪一步最费劲？
2. 现在有哪一小部分可以不用 AI 做？还有哪部分需要帮助？
3. 下次还想做什么，或者这次到这里就够了？

学生拒绝建议、说“不知道”、没有完成、改变时间条件或选择退出，都是有用反馈。助手应接受选择，给出可结束的当前结果，不把退出归因为懒惰，也不继续追问个人原因。需要停止记录时立即停止，已保存材料的删除按本人要求处理。明显痛苦或现实支持需要优先于试用进度。

每完成 3–6 次自愿体验，维护者汇总一次：

- 对话是否帮助当前任务，首次有用内容前有没有多余确认，条件变化后是否调整。
- AI 是否用在合适的部分；哪些任务用简单工具更容易，哪些地方增加了不必要的流程或成本。
- 卡点来自材料、专业知识、运行环境还是助手表达；哪些约束被忽略。
- 成果检查、提示下完成和撤去辅助后的表现分别有什么证据，哪里尚未检验。
- 反馈是否改变下一步，特别检查“完成却无用”“建议被拒绝”和“目标更正”。
- 选最多三处影响最大的修改，每处附匿名证据、预期改善与下一次观察点。

如需与普通 AI 对话比较，使用同一宿主和模型、相近任务难度与投入时间，记录任务顺序及是否重复练习。小样本试用只用于发现可用性问题和改进线索，不据此报告统计显著提升、普遍教学效果或人群排名。

发布报告时分开写“准备了什么”“实际试了什么”“观察到了什么”“仍不知道什么”。未收到真实反馈前，状态持续保持 **待试用**；模型行为测试的进展另见[验证报告](test-report.md)。
