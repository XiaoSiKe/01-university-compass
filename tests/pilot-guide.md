# v0.2.0 小范围学生试用指南

状态：**试用准备材料，尚未开展真实学生试用。** 本文件用于发现入门门槛、对话负担和学习检查中的问题；不用于宣称教学效果或职业收益。模型模拟和人工编写的示范不计为真实学生反馈。

## 参与方式与一次体验

建议先由愿意参与的组织者邀请 3–6 名自愿学生，覆盖没有用过 AI、会用聊天工具但不会编程、已有一点编程经验等情况；专业、年级只是背景，不代替能力判断。每人任选一个当前需要的入口，首次约 20–30 分钟，可缩短、跳过问题或随时结束。学生已有自己的任务时优先使用自己的任务。

开始前用普通话说明：“这是一个仍在改进的学习助手，想看看它是否能帮你处理现在的一件事。做不出来也有价值，我们在检查助手怎样帮助你。你可以不回答、改题、停止，也可以选择不留下记录。”不把参加试用与课程成绩、社团资格、奖励资格绑定；未经本人明确同意不保存原始对话或个人作品。

助手不自行邀请、联系、发送反馈请求或安排提醒。学生需要第二次体验时，由本人选择是否带着结果回来。

## 三个任务入口

| 入口 | 可以直接发给助手的话 | 首次应留下什么 | 变化任务与后续反馈 |
|---|---|---|---|
| AI 帮我学懂一段材料（T01） | “我刚开始学 AI，今天只有 20 分钟。我想用它帮助理解课程，但没有材料在手，请给我一次能检查自己有没有学懂的练习。” | 两道基于材料的题、本人答案、一处核对或纠错；没有材料时使用明确标记的原创模拟材料 | 换一个相似条件，让学生自己判断并说明依据。若愿意，下次用真实课程片段再试，检查是否仍需相同帮助 |
| 用 AI 做一个有用的小成果（T03；有基础者可用 T04） | “我想用两份校园活动报名规则做一页有依据的问答。只有手机，每周两小时，不想买工具。请帮我先做一个能用的小成果。” | 一页有限问答，分别检查材料有答案、没有答案、存在冲突三类问题；保留核对记录和一处改动 | 临时改变一条规则或提出材料没覆盖的问题，观察学生能否修改回答、保留未知或指出冲突。完成却没有用时检查问题和依据，不要求增加功能 |
| 判断下一段该学什么（T05） | “我不知道先把 AI 用于专业学习，还是学开发。请帮我用两项小体验比较一下，每项最多 20 分钟，不要求现在选职业。” | 同一主题下两次有限体验、获得的帮助、感兴趣/卡住的环节、下一段暂定选择 | 比较支持条件是否相近；允许更正目标或停止一条路线。下次反馈要能改变建议，不重复要求重做完整访谈 |

任务参考：[AI 实践卡](../zeroone-university-compass/references/ai-practice.md)、[路径与起点](../zeroone-university-compass/references/ai-pathways.md)。模拟材料和模拟输出只训练对应能力，不能记作实际工具运行、真实课程规则核验或真实用户试用成功。

## 最少记录与两类结果

优先使用匿名编号，如 P01，不记录姓名、学号、联系方式、精确学校班级或无关家庭信息。只有解释具体卡点需要时才记录宽泛背景。默认记录短摘要；保存原话、截图或作品另由参与者决定，分享前删除个人信息与账号凭证。参与者可要求删除自己的试用记录。

建议记录表：

| 字段 | 最小内容 |
|---|---|
| 编号与日期 | 匿名编号、实际日期；未开展时留空 |
| 起点与约束 | 是否做过类似任务、设备、可用时间；不把自报“懂了”当掌握证据 |
| 选的任务与本人目的 | 三入口之一或学生自带任务；用一句话记录希望得到什么 |
| 助手实际帮助 | 解释、提示、完整示范、共同制作中用了哪些；关键时刻是否反复提问 |
| 成果可用性 | 达到哪项可观察标准，哪个实际检查通过/失败；没有运行或真实使用就标未验证 |
| 学生掌握情况 | 能否解释依据、发现错误、改变条件或独立完成关键部分；记录哪一项、用了多少帮助 |
| 卡点与反馈 | 一件最费力/最无用的事、一处有帮助的地方、是否想继续；原话可选 |
| 下一次调整 | 保留、改方法、缩小、换路径或停止；说明哪条反馈导致变化 |
| 记录范围 | 只存摘要/另获同意保存作品；删除要求及处理状态 |

**成果可用与个人学会分别记录。** AI 直接做出正确成果，可以记“成果通过”，同时记“本人掌握未验证”。学生当场在提示下答对，可记“在提示下完成”，不要升级为“可独立完成”。变化题不会时，回到具体概念或步骤给予支持，不将失败解释成不适合学 AI。

同一能力可用四个描述标记：尚未检验、需要完整示范、少量提示可完成、当前变化任务可独立完成。它们只描述这次表现，不用于排学生高低。延迟再做一次或换真实材料，是可选的后续证据，不能补写成已完成。

## 反馈、退出与复盘

结束时最多问三个简短问题，可以不答：
1. 哪一步让你更清楚了，哪一步最费劲？
2. 如果去掉 AI 帮助，你现在能独立完成哪一小部分？
3. 下次还想做什么，或者这次到这里就够了？

学生拒绝建议、说“不知道”、没有完成、改变时间条件或选择退出，都是有用反馈。助手应接受选择，并按已知条件给出可结束的结果；不把退出解释为懒惰，不继续追问个人原因。需要停止记录时立即停止，已保存材料的删除按本人要求处理。

每完成 3–6 次自愿体验，维护者汇总一次：
- 对话是否直接帮助当前任务，首次获得有用内容前有没有多余确认。
- 哪些卡点来自材料、专业知识、操作环境或助手表达；哪些约束被忽略。
- 成果通过和独立检查分别有哪些实际证据，哪里仍未验证。
- 学生反馈是否导致下一步改变；特别检查建议被拒绝、完成却无用、条件变化后的处理。
- 选最多三处影响最大的规则/任务修改，每处附匿名证据、预期改善和下一次观察点。

如需要与普通 AI 对话比较，使用同一宿主与模型、相近任务难度及投入时间，并记录任务顺序；承认熟悉任务带来的练习效应。小样本试用只发现可用性问题和改进线索，不据此报告统计显著提升、普遍教学效果或人群排名。

发布报告时分开写“准备了什么”“实际试了什么”“观察到了什么”“仍不知道什么”。未收到真实反馈之前，状态持续保持“待试用”。
