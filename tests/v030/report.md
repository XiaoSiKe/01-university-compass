# 0.3.0 验证报告

本版在冻结的同一份 Skill 内容上完成实际模型对话、独立语义评阅和原生发现检查。模型沿用本机配置 **gpt-6.1-sol**，没有覆盖模型或修改用户全局设置。所有学生输入均为合成情境；真实学生试用尚未开展。

## 结果与适用范围

| 证据 | 本轮实际结果 | 说明 |
|---|---|---|
| 确定性工具回归 | 23项通过 | 标准库mock及临时项目；不计作真实模型调用 |
| Skill合成情境 | 48例语义通过，0关键失败 | 原16例＋原新增22例＋本轮10例；新例中8例为3轮 |
| 离线实际回答 | 106条 | 48个Skill情境与4个基线情境合计；基线采用只确认对照证据完整 |
| 原生发现与教学 | 4例、6轮，限定范围内通过 | 显式、自然语言、无关代码、多轮教学；不全文注入Skill |
| 本机用户级安装 | 12文件一致，1次独立新会话通过 | 旧版已备份；实际读取已安装入口与新增AI判断资料 |
| 条件隐藏对照 | 4组完成并揭示映射 | 两组相近、一组各有优势、一组Skill小幅更好 |
| 包装 | 12个文件，28张卡，27项来源 | 161个Skill内部相对链接通过；manifest与ZIP匹配 |

这些结果说明给定输入下的行为，不是稳定通过率、统计优势、认证或真实学生学习效果。

## 教学行为与非关键发现

独立评阅覆盖全部实际回答，逐例核对条件贴合、可用帮助、学习检验和反馈调整；不适用的维度不强行要求练习。新增样例观察到：准确材料核验后可直接确认；证据不足保留未知；同一最终测试用于选模型也会影响独立评估；重复错误后缩小任务并增加具体支持；普通表格可作为合适选择；固定流程按失败样例修改；无API的预制比较不记作实际Agent运行；研究和哲学来源不包装成认证或效果保证。

保留5个非关键案例记录：A02有不必要的运行日期旁枝；N01模板与篇幅重复；N05排障较长但给出当前停止点；N08本地密钥配置细节有限；V02直接完成给定证据核对而没有另列操作清单。这些没有构成关键条件冲突。未为追求更有利结果重复抽样或删掉不利记录。

原生多轮第2轮属于解释后的有支持练习；第3轮虽换成同视频帧拆分的新情境且没有解法，但没有随后学生答案。独立掌握、迁移及延迟保持仍然未知。新进程实际历史回放不等于后台持久会话记忆。

## 条件隐藏对照

| 案例 | 揭示后的定性结果 | 主要观察 |
|---|---|---|
| V01 核验无误 | 相近 | 两侧均不强行找错，Skill边界说明较充分、普通对话较紧凑 |
| V03 独立迁移 | 各有优势 | Skill更聚焦模型/阈值选择误区；普通对话覆盖关联数据边界 |
| V05 AI适用性 | 相近 | 两侧尊重普通表格、负责人确认与不贴等级的选择 |
| V06 工作流与Agent | Skill小幅更好 | 对“能核对不等于正确”、按相同规则比较已有输出和缺失侧未评更明确 |

四组使用相同模型配置、学生输入与工具限制，后续历史各自分化；每例单次生成。条件映射在四组评阅完成后揭示。不能据此推断本Skill普遍优于普通对话，或学生学得更多。

## 已修复的工具链问题

- 构建先检查输入与候选包，失败保留旧manifest/ZIP；发布第二个文件失败会回滚第一个。
- 展示页严格选择验收索引指定的文件并核对版本、raw摘要、身份、状态与校验和；新失败或未评审尝试不能取代已采用记录。
- 原生发现默认生成唯一目录，所有新旧入口均拒绝覆盖非空证据目录。
- 版本从Skill元数据读取，数量来自实际文件；历史测试结果冻结。
- 续跑拒绝把脱敏后历史当作原始历史；空筛选不再0/0假成功；指纹绑定版本和raw Skill摘要；同秒尝试按创建纳秒而非随机UUID选择。UTC时间字段也有非UTC环境回归保障。

R0的52个对话全部全新启动，没有使用resume。其实际运行器源码与哈希已保存；之后只修复续跑元数据指纹和同秒排序，由纯桩测试覆盖，提示构造与真实执行路径没有改动。未改写原始模型记录。保存时仅掩码用户/项目绝对路径及运行时排除标识；完整性检查重建全部提示与实际前史哈希，全部匹配。4轮含非空stderr，原文保留供复查；运行完成不替代语义评阅。
