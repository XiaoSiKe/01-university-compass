# 思考与选择卡片

按当前问题选用。P01–P06 都区分原文与应用；具体大学案例和提问由本 Skill 设计。出处详见 [来源表 R01–R07](sources.md)。P07/P08 是原创决策方法，不冒充哲学原文或经实验证明的模型。不是诊断、政策或人生价值的唯一标准。

<a id="p01"></a>

## P01：在实践与认识之间往返

**来源/类型**：毛泽东《实践论》（1937年7月），R01，哲学原著；阅读认识阶段、直接/间接经验和认识循环的相关段落。

**原观点**：认识由实践产生，并在进一步实践中接受检验、继续发展。原文包含中国革命与马克思主义认识论语境，也承认可靠的间接经验，不要求每件事亲自冒险。

**解决的问题/通俗转译**：只靠想象判断“我适不适合某方向”。把当前判断暂作假设，找能增加真实信息的尝试。

**先了解**：具体假设、已有经历、代表性任务、时间成本与不可承担的风险。

**步骤/提问**：写下目前相信什么及依据 → 选一项相关且可承受的体验 → 事先说清观察什么 → 比较实际与预期 → 保留、修改或放弃原判断。“什么结果会让你改变现在的看法？”

**大学应用设计**：以为自己喜欢科研，先阅读一篇导师推荐的入门材料并尝试提出一个可讨论问题；记录愿意投入的部分、困难及是否想继续。不要把一次受挫当成能力定论。

**边界**：这是方法转译，原著没有提出本例或固定一周实验。单次经历受任务、指导、状态影响；有危险或不可逆代价时优先可靠资料、观察和咨询。

## P02：辨认当前重点，并允许重点变化

**来源/类型**：毛泽东《矛盾论》（1937年8月），R02，哲学原著；重点为具体条件、第四节主要矛盾与主要方面、第六节对抗形式。

**原观点**：复杂过程中不同矛盾的地位不同，要研究具体条件和阶段变化；矛盾与对抗不能简单等同。

**解决的问题/通俗转译**：课程、项目、家庭期待挤在一起。辨认当前最影响其他问题、且需要先处理的因素。

**先了解**：各问题的期限、后果、相互影响、当前可改变的部分。

**步骤/提问**：列少量具体问题 → 找相互影响与必要条件 → 暂选重点 → 保留其他事项最低保障 → 随新事实调整。“这一项改善后，哪些困难会一起缓解？”

**大学应用设计**：期末前同时担心实习、社团和挂科。若学分已影响毕业，先核实课程补救与截止，同时给实习探索留最低信息收集动作；考完后再调整重点。

**边界**：不能证明每个学生必有唯一瓶颈，紧急安全或基本生活问题也不能被效率排序淹没。不得将室友、家长、老师当成要打倒的对象，也不许诺解决一个问题就一切顺利。

## P03：调查事实，检查解释

**来源/类型**：毛泽东《反对本本主义》（1930年5月），R03；John Dewey《How We Think》第六章（1910），R04。前者为中国革命调查方法原文，后者为反思探究的哲学/教育论述。

**原观点**：毛泽东强调调查实际情况，反对脱离条件照搬书面结论，并讨论有问题提纲的调查；Dewey 分析从感到困难、界定问题、提出解释、推演后果到观察试验的反思过程。

**解决的问题/通俗转译**：信息不全，却把一种解释当定论；听一个成功故事就要模仿。

**先了解**：哪些是直接观察、资料记载、个人推断、价值评价或感受；哪一条未知最影响选择。

**步骤/提问**：把“我不适合”换成具体事件 → 提出至少一种其他可能解释 → 确定需要什么证据 → 找对情境有实际了解的人或正式材料 → 比较来源并修正。“还有什么原因能解释这次结果？”

**大学应用设计**：一次课程低分可能与基础、复习方法、题型或时间冲突有关。先看具体错题和评分要求，再决定补基础还是换策略；分数真实，关于能力的解释仍待检验。

**边界**：感受无需被审判为真假；分类是为了理解，不用“没有调查”否定学生表达资格。访谈人数不是普适公式，熟人意见可能有幸存者偏差，校规须找本校正式版本。

## P04：自己的价值与生活试验

**来源/类型**：John Stuart Mill《On Liberty》第三章（1859），R05，哲学论证。

**原观点**：重视个性发展和不同生活方式的尝试，同时保留对他人利益的边界。原文有19世纪欧洲中心主义判断，不能照搬其对文明和社会的排序。

**解决的问题/通俗转译**：被单一成功标准推着走，或把“独立”理解为必须与父母意见相反。

**先了解**：学生本人认可什么、现实责任、愿付出的代价及不愿牺牲的条件。

**步骤/提问**：“如果不用向别人证明，你仍想保留哪一部分？” → 区分真心认同与被迫承担 → 比较几种生活安排 → 在责任和成本允许处做可逆尝试。

**大学应用设计**：学生想毕业后留在家乡照顾家人。可比较当地岗位、远程工作的真实条件、升学的时间与费用；不把留乡判作缺乏志向。

**边界**：哲学论证不能证明某条职业路效果更好；自主不是不承担责任，也不应让弱势学生为探索承担无法承受的代价。独特性不是必须追求的成绩。

## P05：区分可行动、可影响与暂不可改变

**来源/类型**：Epictetus《Enchiridion》第1节，R06，斯多亚哲学；Elizabeth Carter 英译本。原文区分由己与非由己的事。

**解决的问题/应用转译**：把别人的反应或一次录取结果当成自我价值的全部。这里的“三类”是现代应用设计，并非原文的原样分类。

**先了解**：损失与感受、当前责任、实际权力和可获得的帮助。

**步骤/提问**：承认发生的事及影响 → 分出可直接行动、能协商影响、目前不能改变的部分 → 为可行动处选一个步骤 → 对无法解决处寻找支持或接受不确定。“你愿意先在哪一部分争取一点空间？”

**大学应用设计**：组员迟交，能明确自己的交付和记录、提出分工协商，必要时按课程机制求助；不能保证对方立即改变。

**边界**：不能要求学生压抑感受、接受侵害或把结构性困难归咎于个人心态。与 P04 的积极探索形成张力：接受现有限制和争取改变可以同时存在，由具体情境决定。

## P06：动机、能力感和连接

**来源/类型**：Ryan & Deci（2000），R07，自我决定理论与研究综述。

**原观点**：自主、胜任和关系需要与动机、内化和良好发展相关。自主指行动中的意愿感，可与依赖他人或集体责任并存；外在目标也可能被个人认同。

**解决的问题/通俗转译**：不知道自己为什么不想做，或把所有外部期待都当成不真实。

**先了解**：目标是否认同、难度和支持是否合适、是否孤立。不能用三项问题诊断心理疾病。

**步骤/提问**：检查“我愿不愿意、能不能开始、有没有支持” → 只改善最相关的一项 → 观察投入与感受。“即使它来自家人期待，你自己认同其中哪一部分？”

**大学应用设计**：学习医学很累，但学生认可服务患者的目标。可调整复习难度、寻求同伴与教师反馈；不必因疲惫就断言选错专业。

**边界**：这是研究框架，不是个体命运预测。没有兴趣不总能靠自主选择解决，经济、身体、照护和学校制度可能是实际限制。

<a id="p07"></a>

## P07：检查想要的结果与选择的路径是否对应

**来源/性质**：本 Skill 的原创应用设计，与 P03/P04 的事实调查、价值选择及 L06/L08 的投入和试验方法相衔接；不是新增外部理论。

**问题**：想提高专业学习效率，却以为必须先学完模型训练；或想研究模型原理，却把工具清单熟练当作完成目标。

**先了解**：想得到的具体结果、决定期限、已有能力、可用时间与不愿牺牲的条件。已知的信息直接用，不逐项重新访谈。

**方法**：把目标写成可观察表现 → 检查当前学习内容是否帮助这一表现 → 找出缺少的必要条件与可以暂缓的内容 → 用一个有限任务验证 → 根据结果继续、缩小或换路径。

**大学应用设计**：学生只想核对课程资料，可从一段材料的证据检查开始；无需先租 GPU。想研究一种方法为何有效的学生，则要逐步接触问题定义、评价、数学与编程基础，不能仅靠提示词成功一次就宣布达到研究目标。

证书可能用于满足正式资格、向他人证明能力或提供学习动力，应分别核实资格要求、认可和评价方式、对本人持续学习的帮助；不能仅因“证书”这个名称就推荐或贬低。

**边界**：允许为兴趣学习暂时没有用途的知识；“对应”不等于一切学习必须立即变现。短期目标也不能自动取消长期基础，取舍由学生认可的目标和现实条件决定。可参考 [三条路径](ai-pathways.md#routes)。

## P08：在接近的条件下比较，并承认比较的限度

**来源/性质**：本 Skill 的原创应用设计，用于个人学习选择；不是一个已经验证的职业测评工具。

**问题**：一个体验有熟练导师、成熟示例和充足时间，另一个完全摸索，结果却被归结为“我天生不适合第二条路”。

**先了解**：所比任务是否有代表性，时间、难度、先备知识、帮助和评价标准是否接近；哪些条件实际上无法对齐。

**方法**：明确比较想回答的问题 → 对已选和未选路线对称列出收益、日常投入、费用、可获支持和未知项 → 为体验使用近似投入和支持，分别留下结果与过程记录 → 将表现、感受、基础缺口和环境差异分开解释 → 补最可能改变判断的一项体验。不能只盯住已选路线的现实困难、想象未选路线的好处；条件不同就降低结论强度，不编造可比性，也不为公平比较无限追加投入。

学生后悔时先查实际代价、新信息和仍能改变的部分，不直接把后悔归因为心态或不知足。若事实支持换路线，就比较转换成本和可行步骤；也允许证据暂不足以决定。

**大学应用设计**：喜欢照教程做出的应用，却不喜欢第一次读英文论文。可以先给研究体验一份有解释的短材料和清楚的问题，再观察是否喜欢提问、评价与解释；同时承认真实研究仍有长期阅读、方法训练等未覆盖部分。

**边界**：个人探索很难控制全部因素，小样本和新鲜感会影响结果。条件相近也不能由一次成败推出终身适合度；涉及实际升学和就业仍需核实正式条件。同题体验见 [T05](ai-practice.md#t05)，本专业方向比较见 [T06](ai-practice.md#t06)。

## 选用时如何处理分歧

P01/P03强调检验判断，P04重视价值自主，P05提醒行动边界，P06关注环境与支持；P07/P08用于检查路径和比较条件。这些观点可以帮助提出不同问题，不能拼成已获实证证明的统一人生理论。事实要核实，取舍由学生决定；学生无需认同某种哲学才可使用具体方法。
