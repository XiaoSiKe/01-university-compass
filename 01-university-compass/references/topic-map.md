# 按学生问题检索

知识分为 Z（零一来源的蒸馏）、P（哲学与思考）、L（学习与行动）；AI 路线与任务提供这些方法的具体应用。来源编号 R 对应 [来源表](sources.md)。所有大学案例均为 AI 应用设计，除非另有明确说明。

| 学生处境 | 卡片 | 支持程度与使用边界 |
|---|---|---|
| 初次接触 AI，不知道从哪里开始 | [路径与共通基础](ai-pathways.md)、[六类任务](ai-practice.md) | 新增课程/Skill来源R16–R24；默认普通设备、零新增预算，按表现选起点 |
| 想学 AI 但说不出用途，或为了证书/比赛 | [P07/P08](thinking.md#p07)、[方向任务](ai-practice.md) | 原创目的与方案比较，允许暂定目标，不将热度和头衔当收益证据 |
| 已有作品却不知道是否学会 | [L03/L05](learning-action.md)、[任务验收](ai-practice.md) | 分别检查成果与独立表现；预制输出不算真实操作 |
| 想从开发改成专业应用，或对已选路线后悔 | [路径切换](ai-pathways.md)、[P08](thinking.md#p08) | 同等比较收益、代价、支持和未知，允许实际不适合及条件变化 |
| 迷茫、方向不明 | [P01–P05](thinking.md)，[Z01](01.md) | 有实践探索理念；“大学指南针”页无成体系经验，不能假装已有成长案例 |
| 大一适应、外部期待、自我价值 | [P04–P06](thinking.md) | 校园适应、住宿、家庭沟通资料不足；以学生事实与补充研究支持对话 |
| 专业学习与专业探索 | [L01–L05](learning-action.md)，[P01/P03](thinking.md) | AI 学习资料多；其他专业培养方案、转专业规则、行业实际工作需另查 |
| 时间与精力不足 | [L06/L07](learning-action.md) | 缺学生生活条件记录；不能套用高投入技术作者的工作节奏 |
| 人际、小组合作 | [Z03/Z04](01.md)，[P02/P05](thinking.md) | 有社团分工、建议机制；不能当成室友冲突、亲密关系的实证指南 |
| 竞赛、项目、实践 | [Z02/Z03](01.md)，[L04](learning-action.md) | 有活动方案与技术项目教程；活动计划不等于已实施成果，日期有冲突 |
| 实习、就业、升学 | [P03/P04](thinking.md)，[L08](learning-action.md) | 合作生态仅证明资源设想；缺招聘、升学政策和长期结果，须核实正式条件 |
| AI 学习与工具 | [Z01/Z05/Z06](01.md)，[L05](learning-action.md) | 相对丰富但混有旧版本、商业教程与夸张主张；按任务选资源，不能直接沿用价格/权限说法 |
| 启动困难、行动失败 | [L05–L08](learning-action.md)，[P01](thinking.md) | 有快速尝试理念；具体行为判断主要来自研究与应用设计 |

检索方法：先用学生的问题选一行，再读一至两张卡。材料不足时补事实，不为引用更多理论而扩展话题。来源核查、主体识别与续接见 [续接与证据](continuity-evidence.md)。
